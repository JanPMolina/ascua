# Inspiración: Guidus (izzle)

Investigación sobre **Guidus: RPG acción roguelike** (`com.izzle.pixeldungeon`), el juego que inspira nuestro proyecto de servidor por turnos. Recopilada el 29-oct-2026.

> Recordatorio del enunciado: el juego **no puede ser una recreación 1 a 1**. Esto es material de inspiración; las reglas finales deben ser propias.
