# Glosario: nombres en pantalla y en el código

El juego muestra nombres simples para que nadie tenga que aprender un vocabulario nuevo. El contrato, el código y los documentos de diseño (`planteamiento/`, `docs/balance.md`) conservan los nombres internos: cambiarlos rompería el protocolo sin aportar nada al jugador.

| En pantalla | Nombre en los documentos | En el cable |
|---|---|---|
| Oro | Ascuas | `embers` |
| Derribado | Caído | `DOWN` |
| Muerto | Extinto | `EXTINCT` |
| Fantasma | Brasa errante | `EMBER_SPIRIT` |
| Traidor | Renegado | `RENEGADE` |
| Ayudar / Vengarse | Camino de la Amistad / de la Venganza | `FRIENDSHIP` / `VENGEANCE` |
| Ganan los Traidores | El Umbral reclama | `THRESHOLD_CLAIMED` |
| Puntos de apoyo | Ecos de la Brasa | `echoes` |
| Mejora | Bendición | `blessing` |
| Elegir mejora | Draft | `DRAFTING` |
| Misión secreta | Pacto | `pact` |
| Ataque marcado | Anuncio | `telegraph` |
| Espera | Enfriamiento | `abilityCooldown` |
| Defender | Guardar | `GUARD` |
| Usar | Interactuar | `INTERACT` |
| Flotar, Frenar, Escudo, Revivir, Luz | Deriva, Estorbo, Avivar, Reavivar, Faro | `MOVE`, `ATTACK`, `ABILITY`, `INTERACT`, `GUARD` |

No cambian el nombre del juego, el Celador, los héroes, sus habilidades ni los nombres de las mejoras. El Eco de Anteayer tampoco: no son los puntos de apoyo del Fantasma.
